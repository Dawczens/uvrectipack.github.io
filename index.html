▶Quick start

Install

  1. Download uv_rectipack-1.0.0.zip. Don't unzip it.
  2. In Blender go to Edit → Preferences → Get Extensions, open the ▾ menu at the top right and choose Install from Disk…
  3. Pick the zip. UV RectiPack is enabled at once, with no restart needed.

First run

  1. Select a mesh and press Tab, then A.
  2. Press N in the UV Editor or the 3D Viewport and open the RectiPack tab.
  3. Click Straighten & Pack. That's it.

Pie menu: Shift+Alt+U in Edit Mode. You can remap it in Preferences → Add-ons → UV RectiPack.

⚡Straighten & Pack - the one-click workflow

The main button does everything in order. It unwraps the mesh if it has no UVs, straightens grid islands, cuts over-long strips, stacks duplicates if enabled, and packs at the largest texel density that fits. A report then shows coverage and density before → after.

How to use

  1. Select one or more mesh objects and press Tab to enter Edit Mode.
  2. Press A to select all faces, or select only the part you want to process.
  3. Open the sidebar with N and go to the RectiPack tab, in the UV Editor or the 3D Viewport. Or press Shift+Alt+U for the pie menu.
  4. Choose a preset and the texture size, then click Straighten & Pack.
  5. Read the report box, e.g. Coverage 59% → 87% · TD 443 → 539 px/m (+22%). Change any option in Blender's Adjust Last Operation panel (F9) and the result updates live.

Options

PresetGame · Desktop/Console, Game · Mobile, Film / Offline or Custom. Sets the margin and the island alignment for you.
Width × HeightTarget texture size in pixels, 256–8192. Non-square sizes such as 2048×256 are supported.
Unwrap FirstAuto unwraps only meshes without usable UVs. Smart UV always unwraps first. Seams by Angle marks sharp edges, then unwraps. Use Existing never unwraps.

▦Straighten islands

Quad islands become clean, axis-aligned grids, so textures, trims and tiling patterns run straight.

How to use

  1. Select the faces. To change the shape only, click Straighten in the Straighten panel; packing is a separate step.
  2. Pick a mode: Proportional keeps the real 3D edge lengths, Even Grid makes all columns and all rows equal, Square makes every quad the same square.
  3. Leave Partial Grids on. Islands with a few triangles, n-gons or poles get their quad region straightened and the rest relaxed around it.
  4. Leave Split Long Strips on for square textures. A strip longer than half the texture is cut along grid lines into equal segments.
  5. Click Orient to rotate any island to its tightest bounding box without reshaping it.

Options

Partial GridsStraightens the quad part of mixed islands. If relaxing would flip a face, the original UVs are kept.
Split Long StripsSquare textures only. Cuts follow grid lines, so seams stay clean.
Orient the RestIslands that are not grids are rotated to their tightest box.
Keep PinnedIslands with pinned UVs are left untouched.

⬒Pack at maximum texel density

Islands are scaled to their true 3D size, so every island gets the same px/m. A multi-strategy rectangle packer then searches for the largest scale that fits. In our tests it gained 10–20% texel density over Blender's built-in packer at the same pixel margin.

How to use

  1. Select the islands and click Pack Max Density, or use Straighten & Pack.
  2. Pick a preset. The info line shows what it means, e.g. Margin 8 px · mips to 512 px · 4 px blocks.
  3. With Separate per Material on, each material gets its own 0–1 space, i.e. its own texture set.
  4. Use Min Island (px) to enlarge tiny islands that would otherwise vanish in the texture.

Options

Game · Desktop/ConsoleMargin stays separated down to the 512 px mip; islands snap to 4×4 px compression blocks.
Game · MobileWider margin, safe down to the 256 px mip; 4×4 px blocks.
Film / OfflineSmall margin, safe to 1024 px; islands snap to whole pixels.
CustomSet Margin (px) and Align yourself: Off, Pixel, 4×4 block or 8 px.
Allow RotationIslands may be turned 90° for a tighter fit.
Uniform Texel DensityRescales every island to its real 3D size before packing.

⧉Stack duplicates

Identical islands, such as bolts, panels and symmetric halves, are packed once and laid exactly on top of each other. The space they free goes to everything else.

How to use

  1. In the Pack panel tick Stack Duplicates.
  2. Keep Mirrored on to also stack mirror-image copies. Turn it off for unique details such as text or decals.
  3. Click Straighten & Pack or Pack Max Density. The report shows how many islands were stacked.
  4. To stack without packing, click the stack icon next to Pack Max Density.

Options

Include MirroredMirrored copies share UVs. This flips the tangent space, which is fine for most game normal maps.
ToleranceHow different two islands may be and still stack (default 1%).

◐Smart Priority

RectiPack casts rays from every face to find what nobody can see: contact areas, interiors and undersides resting on the ground. Those faces get a fraction of the density, and the visible ones get more.

How to use

  1. Open the Smart Priority panel and click Select Hidden Faces to preview. X-ray (Alt+Z) helps.
  2. Tick Shrink Hidden Faces and pack. Hidden faces get Hidden TD × the base density (default 0.25).
  3. Want more pixels somewhere? Select faces and click Hero ×2. For less, click Low ×½. Clear removes the marks.
  4. Tick Other Objects Occlude when other visible objects, such as a floor, should hide faces too.

Options

Hidden TDDensity factor for fully hidden faces, 0.05–1.
Ground PlaneFaces facing or touching the lowest point count as hidden.
Other Objects OccludeVisible meshes outside Edit Mode also block the rays.

Islands that are at least half visible keep full density, so a visible face never loses quality because of a hidden neighbour.

✔UV QC + Fix All

One click checks the whole layout and gives a PASS / WARN / FAIL verdict. You can select the faces behind every issue, fix them automatically and save a JSON report for your pipeline.

How to use

  1. Open the UV QC panel. Choose the scope: All Faces or Selected.
  2. Click Run UV Check. Each issue is listed with a count.
  3. Click the arrow next to an issue to select its faces in the 3D Viewport and the UV Editor.
  4. Click Fix All. RectiPack unwraps missing UVs, re-unwraps folded islands, then repacks and checks again. Intended stacks and priority factors are kept.
  5. Click Export QC Report to save a .json next to your .blend.

Options

ErrorsNo UV map, outside 0–1, overlapping islands, folded faces, zero-area faces.
WarningsCloser than the margin, too small (Min Size px), texel density outliers (TD ±%), stretched faces (Max Stretch).
InfoMirrored islands, listed but never counted as a problem.

Stretch is reported but not auto-fixed, because only you can judge whether it is acceptable.

◑Texel density & stretch heatmap

A live overlay in the 3D Viewport and the UV Editor shows where density is too low (blue) or too high (red). After packing, everything turns green.

How to use

  1. Open the Heatmap panel and pick Texel Density or Stretch.
  2. Reference Median compares against the area-weighted median; Target compares against your Target TD.
  3. The panel and the on-screen legend show the reference px/m and the share of surface within ±20%.
  4. Use the 3D View / UV Editor toggles and Opacity to frame it. Cycle Off → TD → Stretch from the pie menu.

Options

Blue → green → red½× → on target → 2× the reference density.
Priority awareFaces shrunk or boosted on purpose by Smart Priority are compared with their intended density.

⤢Unwrap First

Meshes without UVs work too. RectiPack unwraps them before straightening and packing, still in one click.

How to use

  1. Select a mesh without UVs and keep Unwrap on Auto in the Straighten panel.
  2. Click Straighten & Pack. The report notes the unwrap.
  3. For boxy hard-surface parts, try Seams by Angle, which cuts only sharp edges.

＋More tools

Add to Layout

Packs new islands into the free space of a finished atlas at the same texel density. Everything already packed stays put. Select both objects, select only the new part's faces and click Add to Layout. If the layout is full, only the new part shrinks, and the report says so.

Texel Density tools

The eyedropper measures the selection's px/m. Set TD on Selection scales islands to the target. Analyze Resolution shows the density at 512 to 8192 px and which size your target needs, e.g. 1024 px/m → 4096×4096.

Non-square textures

Set Width and Height independently, e.g. 2048×256 for trims. Straightening and packing work in pixel space, so texels stay square. Long strips are kept whole on non-square textures.

Several objects at once

Select any number of meshes in Edit Mode. With Separate per Material on, faces sharing a material share one 0–1 space.

?FAQ

Does it replace Blender's unwrap?

No. It works on top of any unwrap: seams, Smart UV Project or other add-ons. With Unwrap First it can also unwrap for you.

Will it mess up my pinned or finished UVs?

Only the selected faces are processed. Islands with pinned UVs are skipped when Keep Pinned is on, and Add to Layout never moves existing islands. Every operation is one Ctrl+Z.

Why is the TD lower than before on a fresh Smart UV layout?

Smart UV packs with 0 px margins. RectiPack adds mip-safe margins, and the report says so.

Are the islands packed as rectangles?

Yes. That is ideal for straightened and hard-surface UVs. Other islands are oriented to their tightest box first.

How fast is it?

Under a second for a typical prop. 800+ islands take a few seconds, because it is pure Python.

UDIM?

Not in 1.0. Each material packs into its own 0–1 space.
