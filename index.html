▶Quick start

Install

  1. Download uv_rectipack-1.1.0.zip from Superhive, or the free uv_rectipack-lite-1.1.0.zip from GitHub. Don't unzip it.
  2. In Blender go to Edit → Preferences → Get Extensions, open the ▾ menu at the top right and choose Install from Disk…
  3. Pick the zip. UV RectiPack is enabled at once, with no restart needed.

First run

  1. Select a mesh. Object Mode is fine.
  2. Press N in the 3D Viewport or the UV Editor and open the RectiPack tab.
  3. Click Straighten & Pack. That's it.

Pie menu: Shift+Alt+U in Edit Mode. You can remap it in Preferences → Add-ons → UV RectiPack.

▣Straighten & Pack - the one-click workflowIn Lite

The main button does everything in order. It unwraps the mesh if it has no UVs, straightens grid islands, cuts over-long strips, stacks duplicates if enabled, and packs at the largest texel density that fits. The result box then shows coverage and density before → after, and the UV Check verdict.

How to use

  1. Select one or more mesh objects. In Object Mode the tools work on every visible face of the selected meshes. In Edit Mode (Tab) they work on the selected faces only.
  2. Open the sidebar with N and go to the RectiPack tab, in the 3D Viewport or the UV Editor. In Edit Mode, Shift+Alt+U opens the pie menu.
  3. At the top of the tab set the Texture size and pick a Preset. Then click Straighten & Pack.
  4. Read the result box, e.g. Coverage 59% → 84% · TD 443 → 527 px/m (+19%) on the demo crate, followed by the UV Check verdict. Change any option in Blender's Adjust Last Operation panel (F9) and the result updates live.
  5. If you edit the UVs by hand afterwards, the result box clears itself, so it never describes an old layout.

Options

TextureWidth × Height in pixels, 256-8192. Non-square sizes such as 2048×256 are supported. Custom takes any size from 16 to 16384 px.
PresetGame · Desktop/Console, Game · Mobile, Film / Offline or Custom. Sets the margin and the island alignment for you.
Unwrap FirstAuto unwraps only meshes without usable UVs. Smart UV always unwraps first. Seams by Angle marks sharp edges, then unwraps. Use Existing never unwraps.
Check After PackRuns UV Check on the packed islands and shows the verdict in the result box. On by default.

▦Straighten islandsIn Lite

Quad islands become clean, axis-aligned grids, so textures, trims and tiling patterns run straight.

How to use

  1. Select the meshes or the faces. To change the shape only, click Straighten in the 1 Straighten panel. Packing is a separate step.
  2. Pick a mode: Proportional keeps the real 3D edge lengths, Even Grid makes all columns and all rows equal, Square makes every quad the same square.
  3. Leave Partial Grids on. Islands with a few triangles, n-gons or poles get their quad region straightened and the rest relaxed around it.
  4. Leave Split Long Strips (at the top of the tab) on for square textures. Straighten & Pack then cuts a strip longer than half the texture along grid lines into equal segments.
  5. Click Orient to rotate any island to its tightest bounding box without reshaping it.

Options

Partial GridsStraightens the quad part of mixed islands. If relaxing would flip a face, the original UVs are kept.
Split Long StripsSquare textures only. Cuts follow grid lines, so seams stay clean.
Orient the RestIslands that are not grids are rotated to their tightest box.
Keep PinnedIslands with pinned UVs are left untouched.

⬒Pack at maximum texel densityIn Lite

Islands are scaled to their true 3D size, so every island gets the same px/m. A multi-strategy rectangle packer searches for the largest scale that fits. On the hard-surface demo props with 72-270 islands it gained 12-18% texel density over Blender's own packer at the same 8 px margin. The full version adds Max Fill, below, for round and irregular islands.

How to use

  1. Click Pack Max Density in the 2 Pack panel, or use Straighten & Pack.
  2. Pick a preset. The info line shows what it means, e.g. Margin 8 px · mips to 512 px · 4 px blocks at 2048 px.
  3. With Separate per Material on, each material gets its own 0-1 space, i.e. its own texture set.
  4. Use Min Island (px) to enlarge tiny islands that would otherwise vanish in the texture.

Options

Game · Desktop/ConsoleMargin stays separated down to the 512 px mip; islands snap to 4×4 px compression blocks.
Game · MobileWider margin, safe down to the 256 px mip; 4×4 px blocks.
Film / OfflineSmall margin, safe to 1024 px; islands snap to whole pixels.
CustomSet Margin (px) and Align yourself: Off, Pixel, 4×4 block or 8 px.
Allow RotationIslands may be turned 90° for a tighter fit.
Uniform Texel DensityRescales every island to its real 3D size before packing.
Keep StacksIslands that already lie exactly on top of each other are packed as one and stay stacked. On by default. Turn it off to give every copy its own space.
DensityFull version. Max packs at the largest density that fits. Target packs every texture set at your Target TD in px/m, and the button reads Pack at Target. If the target does not fit, nothing is changed and the report names the texture size that holds it. Max Fill is not used at Target.
TilesFull version. 0-1 packs each texture set into one 0-1 square, as before. Keep Tiles packs every UDIM tile where its islands are. Spread lays the islands out over Tile Count tiles from 1001, 10 per row. Every tile of a texture set gets the same texel density. At Target, Spread uses as few tiles as hold the target.

⬓Max Fill - pack by real shapeFull version

A rectangle wastes the corners of a round or L-shaped island. Max Fill packs the real outline of every island instead, so islands sit in each other's gaps and the whole layout can be scaled up. It is on by default in the full version.

How to use

  1. Leave Packing on Max Fill in the 2 Pack panel. Click Straighten & Pack or Pack Max Density.
  2. The search runs for up to Time Limit (s) (default 2). The status bar shows the time and the gain so far. Press Esc or right-click to stop and keep the best layout.
  3. Read the report. Max Fill +N% over rectangles tells you how much denser the layout is than the rectangle result. It is left out when the gain is under 0.5%.
  4. Switch Packing to Fast for the rectangle packer alone.

Options

PackingMax Fill or Fast. Fast gives the rectangle result with no search.
Time Limit (s)How long Max Fill may search, 0.2-30 s, default 2. A bigger value only adds more tries.
MarginsMargins and the preset alignment are kept. Islands are never shrunk to make room.
Allow RotationMax Fill may turn an island by 90°, 180° or 270° when this is on.

Measured on the demo scenes. On the hard-surface props Max Fill adds 0-1% over rectangles, because rectangles already fill them well, and it skips the search when they do. On organic meshes (10-59 Smart UV islands) it adds 9-18% over rectangles, which is 2-8% more texel density than the best of Blender's three shapes (the lead is small). Above 300 islands, or when a layout is too large to search in time, the rectangle result is used. A 354-island mesh got 1% over Blender this way. Max Fill stops early when it cannot improve the layout any more.

⧉Stack duplicatesFull version

Identical islands, such as bolts, panels and symmetric halves, are packed once and laid exactly on top of each other. The space they free goes to everything else.

How to use

  1. In the 2 Pack panel tick Stack Duplicates and open that section.
  2. Keep Mirrored on to also stack mirror-image copies. Turn it off for unique details such as text or decals.
  3. Click Straighten & Pack or Pack Max Density. The report shows how many islands were stacked.
  4. To stack without packing, click the Stack Duplicates button at the bottom of that section.

Options

Include MirroredMirrored copies share UVs. This flips the tangent space, which is fine for most game normal maps.
ToleranceHow different two islands may be and still stack (default 1%).

◐Smart PriorityFull version

RectiPack casts rays from every face to find what nobody can see: contact areas, interiors and undersides resting on the ground. Those faces get a fraction of the density, and the visible ones get more.

How to use

  1. In the 2 Pack panel open the Smart Priority section. In Edit Mode click Select Hidden Faces to preview. X-ray (Alt+Z) helps.
  2. Tick Smart Priority and pack. Hidden faces get Hidden TD × the base density (default 0.25).
  3. Want more pixels somewhere? In Edit Mode select faces and click Hero ×2. For less, click Low ×½. Clear removes the marks.
  4. Tick Other Objects Occlude when other visible objects, such as a floor, should hide faces too.

Options

Hidden TDDensity factor for fully hidden faces, 0.05-1.
Ground PlaneFaces facing or touching the lowest point count as hidden.
Other Objects OccludeVisible meshes outside Edit Mode also block the rays.

Islands that are at least half visible keep full density, so a visible face never loses quality because of a hidden neighbour.

✔UV QC + Fix AllIn Lite

One click checks the whole layout and gives a PASS / WARN / FAIL verdict. You can select the faces behind every issue, fix them automatically and save a JSON report for your pipeline.

How to use

  1. Open the 3 Check panel. Choose the scope: All Faces or Selected.
  2. Click Run UV Check. Each issue is listed with a count. In the UV Editor the islands behind issues are outlined, red for errors and amber for warnings.
  3. In Edit Mode click the arrow next to an issue to select its faces in the 3D Viewport and the UV Editor.
  4. Click Fix All. RectiPack unwraps missing UVs, re-unwraps folded islands, then repacks and checks again. Intended stacks and priority factors are kept.
  5. Click Export QC Report to save a .json next to your .blend.

Options

ErrorsNo UV map, outside 0-1, overlapping islands, folded faces, zero-area faces.
WarningsCloser than the margin, too small (Min Size px), texel density outliers (TD ±%), stretched faces (Max Stretch).
InfoMirrored islands, listed but never counted as a problem.
Check After PackOn by default. Straighten & Pack, Pack and Add to Layout run this check on what they packed and show the verdict in the result box.

Stretch is reported but not auto-fixed, because only you can judge whether it is acceptable.

Lite shows the verdict and the issue counts. Select Issue, Fix All, the JSON report and the issue outlines are in the full version.

◑Texel density & stretch heatmapFull version

A live overlay in the 3D Viewport and the UV Editor shows where density is too low (blue) or too high (red). After packing, everything turns green.

How to use

  1. Open the Heatmap panel and pick Texel Density or Stretch.
  2. Reference Median compares against the area-weighted median; Target compares against your Target TD.
  3. The panel and the on-screen legend show the reference px/m and the share of surface within ±20%.
  4. Use the 3D View / UV Editor toggles and Opacity to frame it. Cycle Off → TD → Stretch from the pie menu.

Options

Blue → green → red½× → on target → 2× the reference density.
Priority awareFaces shrunk or boosted on purpose by Smart Priority are compared with their intended density.

⤢Unwrap FirstIn Lite

Meshes without UVs work too. RectiPack unwraps them before straightening and packing, still in one click.

How to use

  1. Select a mesh without UVs and keep Unwrap First on Auto, at the top of the tab.
  2. Click Straighten & Pack. The report notes the unwrap.
  3. For boxy hard-surface parts, try Seams by Angle, which cuts only sharp edges.

＋More tools

Add to Layout

Full version

Packs new islands into the free space of a finished atlas at the same texel density. Everything already packed stays put. In Edit Mode on both objects, select only the new part's faces and click Add to Layout. If the layout is full, only the new part shrinks, and the report says so. With Max Fill on, existing islands block only their real shape, so new parts fill holes and corners.

Texel Density tools

In Lite

The eyedropper measures the selection's px/m. Set TD on Selection scales islands to the target. Analyze Resolution shows the density at several texture sizes and which size your target needs. It runs the same search as the pack, with your Uniform Texel Density and Smart Priority settings, and can take up to the Max Fill time limit. E.g. 1024 px/m → 4096×4096 for the demo crate. Lite has the eyedropper; Set TD and Analyze Resolution are in the full version.

Non-square and custom textures

In Lite

Set Width and Height independently, e.g. 2048×256 for trims, or pick Custom and type any size from 16 to 16384 px. Straightening and packing work in pixel space, so texels stay square. Long strips are kept whole on non-square textures.

Several objects at once

In Lite

Select any number of meshes, in Object Mode or Edit Mode. With Separate per Material on, faces sharing a material share one 0-1 space.

Object Mode

In Lite

Straighten & Pack, Straighten, Orient, Pack, Measure TD and Run UV Check also run from Object Mode, on every visible face of the selected meshes. So do Stack Duplicates, Analyze Resolution and Fix All in the full version. They return to Object Mode and keep your face selection. Buttons that need a face selection, such as Add to Layout, Set TD on Selection and the Hero and Low marks, are greyed out there.

UDIM tiles

Full version

Set Tiles in the Pack panel to Keep Tiles or Spread. All tiles use the Texture size. UV Check then looks at each tile on its own: an island that crosses a tile border counts as outside, and overlap and margins are checked per tile. Fix All repairs each tile where it is. Add to Layout puts new islands into the first tile of the layout that has room, or into the next empty tile. RectiPack does not create or change tiled images.

UV Editor overlays

In Lite

While the RectiPack tab is open, the UV Editor shows the 0-1 border and the margin in lime. After a pack, the islands it placed flash for a moment. In the full version, UV Check outlines the islands behind issues until the UVs change. Preferences → Add-ons → UV RectiPack → Overlays turns all of it off.

?FAQ

Does it replace Blender's unwrap?

No. It works on top of any unwrap: seams, Smart UV Project or other add-ons. With Unwrap First it can also unwrap for you.

Is there a free version?

Yes. UV RectiPack Lite is free on GitHub and it is not a trial. It has Straighten & Pack, all straighten modes, packing at maximum texel density with the presets, Unwrap First and the UV Check verdict. The full version adds Max Fill, UDIM tiles, Stack Duplicates, Smart Priority, Fix All, Add to Layout, the heatmap and the TD tools. Installing the full zip over Lite replaces it in place and keeps your scene settings. Download Lite.

Will it mess up my pinned or finished UVs?

In Edit Mode only the selected faces are processed. Islands with pinned UVs are skipped when Keep Pinned is on, islands that are already stacked stay stacked with Keep Stacks, and Add to Layout never moves existing islands. Every operation is one Ctrl+Z.

Does it work in Object Mode?

Yes. Select one or more meshes and click the button. The tools run on every visible face of the selected meshes and return to Object Mode. In Edit Mode they work on the selected faces only. Buttons that need a face selection, such as Add to Layout, are Edit Mode only.

Can it pack at a fixed px/m?

Yes, in the full version. Set Density to Target and type the Target TD. Every texture set is then packed at that density. If it does not fit, nothing is changed and the report says how much fits and which texture size holds the target.

Why is the TD lower than before on a fresh Smart UV layout?

Smart UV packs with 0 px margins. RectiPack adds mip-safe margins, and the report says so.

Are the islands packed as rectangles?

Lite packs rectangles, which is ideal for straightened and hard-surface UVs. The full version packs real shapes with Max Fill, and switching Packing to Fast gives the rectangle result. Other islands are oriented to their tightest box first.

Is it denser than Blender's packer?

On the hard-surface demo props with 72-270 islands, +12-18% texel density over the best of Blender's AABB, Convex and Concave at the same 8 px margin. On organic meshes (a Suzanne, a rock and a torus, 10-59 islands) Max Fill is ahead by 2-8%, a smaller lead. Max Fill itself adds 9-18% there over the rectangle result. Details in the footnote. Your meshes will differ.

What does Max Fill do, and can I stop it?

It nests the real island shapes for up to the time limit (2 s by default). Press Esc to stop and keep the best layout so far. It also stops on its own when it cannot improve. Set Packing to Fast to skip it.

How fast is it?

On our test PC, Straighten & Pack took under 0.1 s for the demo crate (72 islands) and 0.3 s for 1,080 mixed islands. It is pure Python, so a slower machine takes longer.

Does it support UDIM?

Yes, in the full version. Keep Tiles packs every tile where its islands are, and Spread lays a texture set over up to 100 tiles. Every tile of a set gets the same texel density. Lite packs each material into its own 0-1 space.
